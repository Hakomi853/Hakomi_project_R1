# Hakomi_project_R1

个人项目合集，每个项目占一个独立子文件夹，互不干扰。

| 目录 | 项目 | 技术栈 | 说明 |
| --- | --- | --- | --- |
| [`todo-widget/`](todo-widget/) | 每日待办 · 桌面悬浮挂件 | Python 3 + tkinter + HTML | 无边框置顶小挂件，支持每日/一次性/每周/自定义周期任务、到点提醒与打卡历史 |

## 使用约定

- 每个项目自带 `README.md`，说明运行方式和依赖。
- 运行时产生的个人数据（如待办内容、本地配置）统一写入 `.gitignore`，不进入版本库。
- 仓库根目录只放索引、许可证与通用忽略规则。

## 克隆与使用

```bash
git clone https://github.com/Hakomi853/Hakomi_project_R1.git
cd Hakomi_project_R1
```

随后进入具体项目子目录，按其 README 操作。
